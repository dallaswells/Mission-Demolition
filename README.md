# Mission Demolition

Unity version: **2021.3.33f1**. Built-in render pipeline, legacy Input Manager, 3D Rigidbody physics constrained to the XY plane.

// Controls

- Left-drag the red ball backward from the slingshot, then release to fire.
- Pull farther for more speed. Pull downward for an upward launch.
- Hit the green goal with a launched projectile to advance.
- **V** / Whole view: toggle launch-follow view and the whole level.
- **T** / Aim guide: toggle the trajectory preview.
- **Space** / Next shot: reload after a shot, or skip the opening camera move.
- **R** / Retry level: rebuild the current castle. Total shots still include earlier attempts.
- **Escape** or right-click while dragging: cancel the shot.
- After the fourth castle, **Play Again** starts a fresh run.
- **B** / bigmanmode ( ͡° ͜ʖ ͡°) go try it its to make the game cooooler

There is no shot limit. Gold/silver/bronze medals reward efficient solutions without blocking progression. hehehe
